Using RARS in the browser

  • Open an example: File → Open, then go to /str/examples.
  • Open your own file: click Import .asm above; it appears in /str/import. You can also use the ↑ button on any RARS window title bar (goes to /files/uploads).
  • Save: File → Save as… into /files. It stays in this browser (IndexedDB) between visits.
  • Download a file to your computer: save it into /files/downloads; the browser downloads it automatically.
  • /str is read-only: to edit an example, save it under /files first.
